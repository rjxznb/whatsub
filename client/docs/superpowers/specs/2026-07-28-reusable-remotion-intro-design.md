# 可复用 whatsub 精讲片头设计

## 目标

制作一段约 14 秒、可重复用于每期英语精讲视频的 Remotion 片头。视觉采用苹果发布会式的克制运镜和产品展示方式，同时沿用现有 `whatsub-explainer` 模板的深色背景、琥珀与蓝色光斑、金色强调字，确保片头能自然衔接“先盲听 → 逐句精讲”的正片。

每期只替换视频封面、标题、链接和 whatsub 操作录屏，不修改动画代码。

## 画面时间轴

### 0–2.8 秒：本期素材

- 深色背景为 `#08090d`，左上琥珀光斑、右下蓝色光斑缓慢呼吸。
- 本期视频封面以悬浮玻璃卡片进入画面，并进行轻微推近。
- 显示本期视频标题和 URL。
- 一条琥珀色扫描光经过 URL，建立“复制链接”的动作意图。

### 2.8–5 秒：进入 whatsub

- MacBook 外壳从暗处升起并展开。
- 视频封面卡片缩小，沿平滑曲线飞入 MacBook 屏幕中的 whatsub 导入界面。
- URL 落入输入框，导入按钮产生一次柔和脉冲。
- 运镜和元素变化使用基于帧的 Remotion 动画，禁止依赖 CSS transition。

### 5–10.8 秒：真实操作录屏

- MacBook 屏幕无缝切换为本期提供的真实录屏。
- 录屏内容包括填入链接、开始下载以及进入转录与 AI 解析画面。
- 录屏必须完整显示，使用 `object-fit: contain`，不得通过 `cover` 裁掉界面。
- 屏幕空余区域使用同一录屏的放大模糊层填充，Mac 外壳、反光和阴影保持可见。
- 允许通过配置指定录屏起止时间和播放速度。

### 10.8–14 秒：进入精讲

- 解析状态完成后，镜头快速推入 MacBook 屏幕。
- 屏幕扩展至铺满整个 9:16 画面。
- 显示“现在，进入今天的精听精讲”。
- 使用金色闪光与短运动模糊衔接现有精讲模板的“先盲听”段。

## TTS

固定口播采用以下版本：

> 在开始精讲之前，我们还是先用 whatsub 处理一下今天的视频。把链接粘贴进去，它会完成下载、本地转录和双语解析，也会帮我们找出这段内容里值得学习的地道表达。好了，现在进入今天的精听精讲。

TTS 固定使用 `edge-tts`，不使用 MiniMax：

- 中文旁白使用 `zh-CN-YunjianNeural`（云健）。
- 英文单词、英文例句及需要单独发音的品牌英文使用 `en-US-AndrewNeural`（Andrew）。
- 中文正文里的 `whatsub` 默认交给云健连贯朗读；只有需要突出标准英文发音时，才拆分给 Andrew，避免频繁切换音色破坏口播连续性。
- TTS 生成后先读取实际音频时长，再在 13–16 秒范围内调整 Remotion Composition 时长和各场景节点，禁止强行截断或明显加速语音。
- 音频作为独立输入由模板配置传入，保证片头与现有精讲生成器使用相同的中文和英文音色。

## 可替换配置

```ts
type IntroConfig = {
  coverImage: string;
  videoTitle: string;
  videoUrl: string;
  screenRecording: string;
  recordingStart: number;
  recordingEnd: number;
  recordingSpeed: number;
  ttsAudio?: string;
};
```

- `coverImage`：本期封面图。
- `videoTitle`：本期素材标题。
- `videoUrl`：本期视频链接。
- `screenRecording`：本期 whatsub 导入及解析录屏。
- `recordingStart` / `recordingEnd`：取用录屏的时间范围。
- `recordingSpeed`：录屏倍速。
- `ttsAudio`：可选 TTS 音频；未提供时输出带静音音轨的成片。

## Remotion 组件边界

- `MaterialCard`：封面、标题和链接展示。
- `MacBookFrame`：MacBook 外壳、屏幕遮罩、反光和阴影。
- `ImportAnimation`：封面和 URL 进入 whatsub 的动画。
- `ScreenRecording`：录屏裁时、倍速、完整显示和模糊背景。
- `FinalTransition`：屏幕推满、结束文案和金色闪光。
- `ReusableIntro`：读取配置并组织各段 Sequence。

组件只通过配置和时间参数通信，单个组件不读取其他组件内部状态。

## 输出与复用

- 分辨率：1080 × 1920。
- 帧率：30 fps。
- 时长：约 14 秒；允许根据 TTS 实际时长在 13–16 秒之间微调。
- 编码：H.264 MP4，兼容剪映、Premiere 和现有精讲生成器。
- 提供一个示例配置和一条渲染命令。
- 首版使用现有帮助录屏作为占位；用户提供真实导入录屏后，只替换配置中的素材路径重新渲染。

## 验收标准

1. 四段叙事连续、转场没有生硬跳切。
2. MacBook 屏幕内的录屏完整可见，任何边缘和按钮不得被裁掉。
3. 封面、URL、录屏可以仅通过配置替换。
4. 背景、字体和强调色与 `whatsub-explainer` 深色模板一致。
5. 最后一帧能够自然衔接精讲视频的“先盲听”段。
6. 抽查四个关键帧，并播放完整成片确认无黑帧、错位、卡顿和音画截断。

## 错误处理

- 素材文件不存在时，渲染前明确报出缺失路径。
- 录屏起止时间越界时终止渲染，不静默输出黑屏。
- 录屏比例异常时仍使用 `contain` 完整显示，并由模糊背景填满屏幕区域。
- TTS 音频缺失时保留静音音轨，确保进入剪辑软件后时间轴行为稳定。
