# 订阅价格单一来源设计

## 背景

桌面端的订阅价格是散落在组件和注释中的静态文本。邮箱登录卡片仍显示“月度 ¥22 / 年度 ¥168”，云同步限制提示仍显示“¥12/月”，而当前价格已经调整为月订阅 ¥38、年订阅 ¥348。代码中没有统一的桌面端价格来源，也没有测试阻止旧价格重新出现。

## 目标

1. 所有当前用户界面统一显示月订阅 ¥38、年订阅 ¥348。
2. 桌面端运行时文案只从一个模块读取价格。
3. 价格格式由共享函数生成，组件不再拼写价格数字。
4. 测试覆盖邮箱登录卡片和三种云同步升级提示。

## 非目标

- 不在本次改动中新增后端产品目录接口。
- 不改变支付、订阅校验或许可证逻辑。
- 不把历史设计文档中的旧价格当成运行时配置。
- 不触发发布或 CI。

## 设计

新增轻量模块 `src/config/subscriptionPricing.ts`，导出只读价格对象和面向 UI 的格式化值：

```ts
export const SUBSCRIPTION_PRICING = {
  currency: "CNY",
  monthly: 38,
  yearly: 348,
} as const;

export const MONTHLY_PRICE_TEXT = `¥${SUBSCRIPTION_PRICING.monthly}`;
export const YEARLY_PRICE_TEXT = `¥${SUBSCRIPTION_PRICING.yearly}`;
```

`LicenseGate` 使用共享值生成“月度 ¥38 / 年度 ¥348”。`SyncButton` 的额度、文件大小和时长限制提示统一生成“升级 Pro（¥38/月）”。相关类型注释与当前代码注释同步更新，避免维护者继续依据旧数字修改 UI。

桌面端常量是离线可用的展示回退值。未来若许可证服务提供公开产品目录，可以在不改变调用组件的前提下替换该模块的数据来源；本次不引入启动网络请求，以免登录门禁因价格接口不可用而阻塞。

## 数据一致性

- 当前唯一运行时值：月订阅 `38`，年订阅 `348`，币种 `CNY`。
- 组件不得出现 `¥12`、`¥22`、`¥168` 的运行时字面量。
- 支付后端仍是实际扣款金额的最终来源；桌面端只负责展示。

## 测试策略

- 纯配置测试断言月价为 38、年价为 348。
- `LicenseGate` 测试断言同时渲染 `¥38` 和 `¥348`，且不渲染旧价格。
- 参数化测试覆盖 `SyncButton` 的额度、大小和时长三种限制，均显示 `¥38/月`。
- 源码守卫只扫描运行时 `src/`，拒绝新增 `¥12/月`、`¥22`、`¥168`。

## 风险与降级

若后端价格再次变化，仍需要更新一个桌面端常量，但不会再遗漏多个组件。动态产品目录可作为后续独立项目，不纳入本次修复范围。
